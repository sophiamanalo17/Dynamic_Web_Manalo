## Final Project Idea + Explaining State

As I am traveling a lot for winter break, I plan to build a travel planner where users can create trips, organize activities into daily itineraries, and check off activities as they complete them. I'll use `useState` to manage trips, activities, completion status, selected trips/days, and form inputs, while using props to pass trip and activity information to child components. I don't plan to use Context or Redux because the state is relatively simple and can be managed by a shared parent component.

# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).
